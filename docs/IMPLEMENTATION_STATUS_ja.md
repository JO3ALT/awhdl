# AWHDL実装状況

[English](IMPLEMENTATION_STATUS.md) | 日本語

> この日本語版を規範文書（正本）とします。英語版は参考訳であり、差異がある場合は日本語版が優先されます。

## リリース状態

- 仕様: ドラフトv0.2
- コンパイラプロトタイプ: Milestone 1
- CLI: `aic check`のみ
- ランタイム適合実装: 未実装

## 実装済みの構文

- エンティティ宣言とポート
- アーキテクチャ宣言
- 単純なデバイス宣言
- 初期値を省略可能な単純な信号宣言
- 感度リストを持つプロセス
- 出力を1個持つデバイス呼び出し
- 信号代入
- `null`文
- `--`で始まるコメント
- `text<internal>`のように機密区分を省略可能なデータ型

## 実装済みの検査

- 行・列を伴う構文エラー
- エンティティおよびポートの重複
- 未知のエンティティを参照するアーキテクチャ
- デバイス、信号、ポート／信号名の重複
- プロセス感度リスト内の未知の名前
- 未知のデバイスに対する呼び出し
- 未知の出力先に対する呼び出しまたは代入

## 解析するが意味を強制しないもの

機密区分名はASTに保持しますが、まだラティスとして検証しません。したがって、検査成功はセキュリティ上の情報フローが安全であることを意味しません。

## 未実装

- `if`、`case`、タイマー、タイムアウト、並列処理、予算、アサーション
- デバイスのジェネリック、ポート、能力、配置、クリアランス
- 機密区分フロー、テイント伝播、機密解除
- バージョン付きJSON IR
- イベントスケジューリングとデルタサイクル
- AWHDL設計からのMCPまたはエージェント呼び出し
- クラウド外向き通信の認可とサンドボックス実行
- `aic compile`、`sim`、`run`、`graph`、`audit`

未対応の構文は無視せず、必ず診断を生成しなければなりません。
