> この日本語版を規範文書（正本）とします。英語版は参考訳であり、差異がある場合は日本語版が優先されます。

AWHDLの改訂版を公開する前に、次を確認します。

1. 該当する場合、READMEが仕様をドラフトと明記している。
2. プロバイダー名と製品名は非規範的に扱うか、予約済みの例示用プレースホルダーを使う。
3. 資格情報、非公開エンドポイント、個人ユーザー名、ホームの絶対パス、非公開プロジェクトパス、生成された実行状態、ビルド出力を公開しない。
4. サンプルが独自ソフトウェアやクラウド資格情報なしで動作する。
5. `IMPLEMENTATION_STATUS.md`をテスト済みの動作と一致させる。
6. 日本語版を正本、英語版を参考訳として表示し、英語版の変更を対応する日本語版へ先行させない。
7. ルートと`docs/`に置く仕様書複製の本文が同等であり、配置に応じた相対リンクが有効であることを確認する。
8. ワークスペース全体でフォーマット、テスト、Clippyを実行する。

環境固有情報の推奨スキャン:

```bash
rg -n '/home/[^/ ]+|/Users/[^/ ]+|192\.168\.|10\.[0-9]+\.|api[_-]?key|private[_-]?key' \
  --glob '!target/**'
```

一般的な例示に一致する場合もあるため、検出結果は手作業で確認してください。一致だけでは情報漏えいの証明にはなりません。
